
## What is Docker?
 - Docker is a platform that allows you to package an application and all its dependencies into a container.

### Think of a container as a lightweight, portable box that contains:
- Your application
- Required libraries
- Dependencies
- Configuration files

This ensures the application runs the same way on any machine.

## Why Docker?

### Without Docker:
- "It works on my machine" problems
- Dependency conflicts
- Different operating systems cause issues

### With Docker:
- Consistent environments
- Easy deployment
- Faster development
- Scalability

### Docker Daemon
- Runs in the background and manages containers.

### Docker Image
- A blueprint/template for creating containers.

### Docker Container
- A running instance of an image.

### Docker Hub
- A cloud repository for Docker images.

### Dockerfile
- its doesn't have an extension
- it helps you create/build an image

### Dockerize a fastapi application
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello Docker"}
```

```Dockerfile
FROM python:3.12

WORKDIR /app

COPY requirements.txt .

RUN pip install -r requirements.txt

COPY . .

CMD ["uvicorn", "main:app",
     "--host", "0.0.0.0",
     "--port", "8000"]
```

### Run
```bash
docker build -t fastapi-demo .

docker run -p 8000:8000 fastapi-demo

```

### Docker Compose
- A tool for defining and running multi-container Docker applications.
- Manages multiple containers
- `docker compose version`
- mysql -u admin --port 3306 --host localhost -p
- docker build -t contain_name:tag
- docker run -p 5001:5001
  
```yaml
services:
  elbowpay:
    build: .
    ports:
      - "5001:5001"

  db:
    image: mysql
    environment:
      MYSQL_ROOT_PASSWORD: password
```

### Run
```bash

docker compose up -d
docker compose down
```

## Docker Volumes
- Used to persist data generated by and used by Docker containers.
- Containers are temporary
- Data is lost when containers are deleted
```bash
docker volume create my_volume
docker volume ls

docker run -v mydata:/data ubuntu
docker run -it --name ubuntu-demo -v $(pwd)/mydata:/data ubuntu bash
# inside the container
echo "Hello Docker Volume" > /data/message.txt
cat /data/message.txt

# remove container
docker rm -f ubuntu-demo
# verify data persist
docker run -it --name ubuntu-demo2 -v $(pwd)/mydata:/data ubuntu bash
cat /data/message.txt

# inspect volume
docker volume inspect mydata

# remove all unused volume
docker volume prune

docker run -d -it --name elbowpay  -v $(pwd)/mydata:/deploy/data elbowpay:v0.0.2

# bind mounts (share local folder with container)
docker run -v $(pwd):/app python-app
```
